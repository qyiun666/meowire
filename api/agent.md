# MeowAgent meowire api — facade + composition root

## Purpose

- Facade: Agent struct — Stimulate returns `iter.Seq[Event]`, Close shuts down
- Composition root: assemble.go is the single assembly point (port validation, cell wiring)
- Types: re-exports all internal contract types (ports, data packets, events, memory)

## Dependencies

- internal/brain (the bundled organ — the one provider package; openai-go v3)
- internal/cell (agent kernel)
- internal/nerve (Event, ports, Hooks, MethodSpec)
- internal/nerve itself stays standard-library only; the openai-go import stops at internal/brain

## Sealed Internals

- All implementation packages live under internal/ and are not importable
  outside this module (Go compiler enforced)
- This api package is the sole public surface: New/Stimulate/Close plus the
  contract types in types.go
- Hosts fill the brain parameters (`Organs.Brain`) and implement the six ports against
  api-package aliases (Effector/Closer/Hooks/Sandbox/ContextBudget/Memory); they never touch
  internal packages directly and never import an SDK

## Interface Contract

- `Organs{ID, Brain, Act, Closer, Hooks, Sandbox, Budget, Mem, System, Identity, Methods, Tools, Context}`: host port container — **the brain parameters plus all six ports required, every hook callback required** (H1–H8: explicit no-op, not absence), a missing port, callback or brain parameter (Model/Key, or a `Mode` outside the enum) returns an error (no stubs, no optional port; the brain is the one organ the framework itself provides). Nothing between two agents is modeled here. `ID` is required too (no default name): see below. The composition root constructs the bundled brain (`internal/brain`) from `Organs.Brain` and injects it as the cell's Think port — the loop never learns which organ filled it
- `Blueprint{Organs, Config}`: host assembly blueprint instance; define the wiring once, `New` many times — with `Organs.ID` as the field to vary per instance (and a port that declares `Bootable` built per instance, since it joins one assembly each). `New(b Blueprint) (*Agent, error)` runs three steps in order — validate the blueprint, bring up the organs that declared `Bootable`, construct the cell — and error-level findings (missing ports, incomplete ports, an unnamed agent) always block; info findings never block. A failing `Boot` aborts assembly and releases what the attempt opened through the host `Closer` (the framework never closes an organ, so a failed assembly leaves no resource behind on the one channel it knows). No Strict flag: every wiring point is required, so there are no warn-level findings to promote
- `FullHooks(h Hooks) *Hooks`: assembly helper — returns a copy with every nil callback filled by an explicit no-op; hosts declare only the hooks they need
- `GuardStack(layers ...Sandbox) Sandbox` / `FallbackEffector(ports ...Effector) Effector`: organ combinators — several implementations behind the one port the loop sees. Each returns an **existing** port type, so a composed organ is interchangeable with a plain one (no slot, no data type added): a membrane stack rules as one (Deny beats Ask beats Allow, the first Deny short-circuits so a later permissive layer gets no vote, a layer error is the port contract's own fail-closed Deny, `Bounds()` reports the first non-empty boundary, an empty stack denies), a fallback port takes the first member that answers without an execution error and joins every member's error when all of them fail. `Effect.Err` is a business result, not a broken organ, so a fallback effector never moves on for it
- `Bootable{Boot(ctx context.Context) error}`: optional lifecycle capability any host port may declare — the framework calls it once per organ instance, in `PortOrder()` sequence (the blueprint's required phase-2 ports, derived from `Connectome()` rather than listed beside it). Boot is **not** Close's counterpart: it opens nothing the framework owns, so a failed Boot is released through the host `Closer`, never by closing organs
- `Config{MaxRounds, MaxToolOutput, MaxRetries, ToolTimeout, ToolMaxRetries, ParallelActs, MaxParallelActs}` (alias of `nerve.LoopConfig`): zero values fall back to defaults (8 rounds, no truncation, no retry, no per-tool timeout/retry, strict serial tools); ParallelActs (opt-in) executes a round's multi-tool batch concurrently — serial gating → parallel Act → serial feedback in call order; prerequisite: concurrency-safe Effector (Validate surfaces an info finding when enabled, and one when a `MaxParallelActs` ceiling is set while the switch is off, since then it binds nothing); MaxParallelActs caps how many calls of a batch run at the same time (<=0 = the whole batch at once); `UpdateConfig(cfg)` swaps wholesale at runtime (next Stimulate/Resume takes effect, in-flight loop keeps its snapshot), `GetConfig()` reads current values (read-modify-write; a zero field resets to default)
- `Organs.ID` is required and has no default: it is the identity every event carries (`Event.CellID`) and the one a `Session` is checked against on `Resume`, so a shared default would let one agent accept another's suspension handle and answer with its own organs. Uniqueness among live instances is the host's declaration — the framework cannot see its siblings
- Facade methods are thin delegates: `Stimulate` → Cell.Stimulate (returns `iter.Seq[Event]`); Close → Cell.Close + host Closer; Close is idempotent
- `Pause()` / `Unpause()`: Agent-level pause control — idempotent, concurrency-safe, no-op after Close; takes effect at the next gap point (before each Think / tool execution); a pause yields EventState(StatePaused) + EventPaused (Session snapshot) and ends the iterator normally — resume via `Resume(sess, Response{})` (unified suspension-resume); `Unpause()` only clears a pause request that has not taken effect yet; the loop backs out that request when it resumes **the pause it honored**, and leaves a standing request alone when the resumed suspension was some other flavour (a request belongs to whichever loop is running; eating it would silently drop the host's Pause)
- `Resume(ctx, sess Session, resp Response) iter.Seq[Event]`: continues a suspended loop from the Session captured in EventWaitInput (tool or membrane-ask suspension) or EventPaused (pause suspension). Which field of the `Response` the loop reads is decided by `Session.Kind()`, never by the answer's text: **WaitTool** — `Answer` becomes the pending tool's structured result (a ToolResults entry echoing the pending call; its ID travels as the model supplied it, and an empty ID does not void the answer — Name is the identity that survives, as on the executed path), `Deny` records that call as failed in `ToolResults.Err`; **WaitPause** — nothing is asked, neither field is read, the loop just continues; **WaitCallAsk / WaitUtterance** — `Deny` refuses with that reason (feedback lands in the canonical `[sandbox-denied: ...]` form, the answer grammar and the feedback text being distinct shapes), an empty `Deny` with a non-empty `Answer` approves (the pending call runs without re-gating, or a withheld draft is said exactly as generated with no second Think), and the zero `Response` declines as `[sandbox-denied: declined]` so not answering fails closed. Remaining tools of the suspended round run first, then the round loop resumes from the suspended round (no extra round, no budget during the wait); stream/hooks/guarantees isomorphic with Stimulate; zero-value Session rejected with an error event; after Close yields ErrCellClosed; persistence round-trip via `Session.Marshal()` / `meowire.UnmarshalSession(data)` (versioned JSON, cross-process recovery)
- `Replace(slot, port) (any, error)`: dynamic wiring — runtime port swap (SlotAct/SlotSandbox/SlotBudget/SlotMem/SlotHooks — the set the blueprint's WirePoint.Slot values own; the brain has no slot, a different model is a new assembly); takes effect at the next Stimulate (in-flight Stimulate keeps its ports); returns the previous port; concurrency-safe; after Close it reports `ErrCellClosed` and leaves the incoming port alone; **rejects nil/incomplete ports** (Budget needs Trimmer+TrimResults+MaxTokens, Hooks needs all eight callbacks); the Closer (resource binding) and the pause gate (framework wiring behind Pause/Unpause) are never swappable; every successful swap records a `ReplaceAudit{CellID, Slot, OldType, NewType}` (ports named by Go type, not held — the record is emitted after the swap and must stay serializable) emitted as EventReplace at the start of the next Stimulate/Resume (the moment the swap takes effect), before any other event; an incoming organ that implements `Bootable` is brought up **after** the slot has accepted it and **before** the swap commits, so a mistyped slot never spends the organ's one startup, a dead replacement never takes effect mid-round, and the live wiring is untouched when Boot fails; the displaced organ is never closed (an in-flight Stimulate may still hold it — retiring it is the host's decision)
- `Agent.ID() string`: the cell identity the blueprint assigned (`Organs.ID`, which `New` requires to be non-empty)
- `EncodeEvent(Event) ([]byte, error)` / `DecodeEvent([]byte) (Event, error)` (with `WireEvent`, `WireErr`, `WireVerdict`, `WireWait`): the event stream's portable form, for a host that journals events or replays them in another process. Every record carries `Version` (currently 2), and a mismatch — including a journal written by the version this build retired — is rejected rather than read as a best-effort match; an unknown kind/state/ruling name or a stale embedded `Session` likewise, and the **encoder** refuses an enum outside its name table too, so a journal never holds a line its reader must reject. Every event also carries `CellID`, `Seq` and `TS` — the cell, its emission order and its emission moment — stamped at the cell boundary, so a merged log still says who spoke, in what order, and when. A value the wire cannot carry (an error the framework does not own) comes back as the same text, and the event names the loss in `Dropped`
- After Close, Stimulate returns ErrCellClosed
- Errors: `ErrCellClosed`, `ErrMaxRounds` and `ErrForeignSession` are all defined in nerve and re-exported here via errors.go — a refusal the framework raises must be matchable by identity from a host that cannot import internal/, and every one of them is in the event wire's `frameworkErrs` name table so it survives a journal by value (a guard test fails if a declared sentinel is missing from that table)

## Wiring Blueprint (graph-based assembly inspection)

- The blueprint is a **graph**: `ConnectomeNodes()` are the data-object nodes (prompt/context/toolresults/plan/bounds/decision/action/effect/err/output/timing/resources/hooks); `Connectome()` is the slot edge list (ports P2–P7 plus the P5b/P5c/P6b/P7b sub-slots and the optional P3b lifecycle point (filled exactly when the host's `Closer` implements `Bootable`), hooks H1–H8, built-ins F1/F2/G1 — F2 is the bundled brain; there is no P1: that slot belonged to the removed Thinker port). Each edge carries ID/Name/Phase(1 framework·2 host port·3 hook)/Category(sense-decide-act)/TargetID(graph node it reads or mutates)/Target(that edge rendered as words — what the slot takes and what it leaves behind, which one node id cannot say)/Semantics(replace-append-trim-gate-read-only-act-container)/Required/Slot(Non-empty = the name `Cell.Replace` accepts for it — the single source of the swappable-slot list, which `nerve.SwappableSlots()` derives and both `cell`'s dispatch table and the `api` `Slot*` constants are tested against)/Desc
- `WiringDiagram(o Organs) []Slot`: extracts actual assembly state (filled/unwired) from Organs — no host registration needed; built-ins always filled
- Find-by-function is a filter, not a call: every edge carries `TargetID`, so "who touches this data object" is one pass over `WiringDiagram`/`Connectome`. The node→edge mapping itself is pinned by `TestConnectomeNodeCoverage` (nerve), which writes its expected sets out rather than deriving them from the blueprint under test
- `Validate(o Organs, cfg Config) []Issue`: blueprint × assembly comparison. Levels: error (required slot missing or incomplete — ContextBudget missing Trimmer, TrimResults or MaxTokens — a `Brain.Mode` outside the enum, or `Organs.ID` empty), info (empty Identity/Tools/Context, MaxRounds<=0 default, ParallelActs enabled without a concurrency-safe Effector). No warn level: a missing wiring point is a missing organ — an error
- `RenderDiagram(o Organs) string`: ASCII wiring graph (nodes section, then one edge per line with [x]/[ ] mark, -> target node, and the blueprint's own reading of that edge in brackets — the same `Target` text `RenderJSON` carries, so the two renderings of one graph say the same thing)
- `RenderJSON(o Organs) ([]byte, error)`: machine-readable counterpart — marshals the assembled graph (nodes + slots with filled state) as indented JSON
- Result types: `Slot{Wire WirePoint, Filled bool}` (blueprint entry + filled state), `Issue{Level IssueLevel, Wire, Msg string}` (Validate finding; `Level` ∈ error/info; `Wire` names the slot the finding is about, and `""` is a finding about the assembly as a whole — which no slot list can point at), `IssueLevel` constants `LevelError` / `LevelInfo`
- `New` rejects error-level findings always (missing/incomplete ports, joined via errors.Join); info findings never block; hosts surface them by calling Validate at assembly/test time

## Key Decisions

- Flat model: one Agent = one kernel; host manages multiple instances for multi-agent
- Sub-agent = host tool pattern (spawn_agent tool), not framework-level nesting
- History managed by host (MemHop): host controls context accumulation via Organs.Context
- Structured tool feedback: Prompt.ToolResults ([]ToolResult{ID, Name, Result, Err}) is the single tool-feedback track — tool results never enter Context (text track keeps host-injected base + sandbox denials); ID is the LLM-provided call id (call_xxx), Result/Err carry the truncated raw output (Err non-empty = failed); Resume preserves the accumulated track and appends the response as the pending tool's entry; EventToolResult echoes the call (Event.ToolCall). Rendering (tool-role messages, [tool_call_id=xxx] markers, plain text) is the bundled brain's decision — the pairing is rebuilt from ToolResults each round
- Host-driven multi-round resume (Step-Resume) = stop iterator + self-managed history + re-Stimulate; each Stimulate is one stateless step
- Streaming: `WithSink(ctx, sink)` mounts the brain's delta channel on the Stimulate context (arrives before the output membrane rules; stream-and-correct on EventText); the event stream is an observation mirror of loop execution — EventText stays whole-segment, token deltas never enter it
- ask_user: the tool returns `&Effect{WaitInput: question}` — the loop yields StateWaiting + EventWaitInput (with an opaque Session) and ends the iterator normally; the host saves the Session, shows the question, and calls `Resume(ctx, sess, Response{Answer: input})` once the input arrives (timeout host-controlled, default deny `Response{Deny: "timeout"}`, which records the call as failed). Never block inside Act — blocking drags the Close wait
- Membrane ask (tri-state rulings): `Sandbox.Allow` or `Sandbox.Emit` returning `VerdictAsk` suspends through the identical StateWaiting + EventWaitInput pair (Question comes from the ruling, not a tool effect; an utterance ask carries a zero `Call` and keeps its draft inside the Session, so the withheld text is never in the event stream); the resolve uses the same Resume channel and answers with a ruling, not a string match (`Deny` refuses, an empty `Deny` + non-empty `Answer` approves — approved calls execute without re-gating, an approved draft is said as generated without re-Thinking; the zero `Response` declines); the audit chain closes with a terminal second EventSandbox record
- Dynamic memory injection: Stimulate has no per-round context channel; per-round retrieval happens in Hooks.BeforeThink; host controls once-vs-every-round semantics with its own closure flag
- Guards/emotion/plan: ContextBudget trims both accumulating tracks before each Think — text Context via Trimmer, structured ToolResults via TrimResults (trimmer, not hard stop); MaxRetries retries Think only — tool-failure guards are host-side (Effector or AfterAct); ToolTimeout/ToolMaxRetries bound tool execution (per-attempt timeout; retry on effector err only, Effect.Err never retried); identity/emotion is host-composed into the `Identity` string and rendered by the brain; Plan is a host-serialized string injected via BeforeThink and updated via AfterThink
- Sandbox: host membrane guarding **both sides of the loop** — `Allow(ctx, Action)` before a tool runs (allowlist/denylist, ask-confirm) and `Emit(ctx, Utterance)` before a round's text is heard (egress review), each returning the tri-state `(Verdict, reason string, err error)`: Deny (zero value, fail-closed) — on the call side appends `[sandbox-denied: ...]` feedback, on the text side replaces that round's draft with the same text (which also joins Context), Allow proceeds, Ask suspends for external confirmation (see above), err coerces to Deny with reason `sandbox error: <err>` (feedback lands as `[sandbox-denied: sandbox error: ...]`), and so does a ruling value the name table has no entry for (`knownRuling` in gate.go — an unnamed value has not permitted anything); every ruling first yields EventSandbox carrying a `SandboxVerdict{CellID, Call, Ruling Verdict, Reason, Question, Err}` (a zero `Call` marks the utterance side; ask chains close with a terminal resolve record); a tool denial then yields EventToolResult(Err) and the loop continues; Sandbox.Bounds() is snapshotted once per Stimulate into Prompt.Bounds (execution boundary description surfaced to the LLM)
- Memory port vs the text track (dual track, no overlap): P7 fills the structured `Prompt.Memories` from `Memory.Recall` before every Think; H3 (`BeforeThink`) overwrites the text track `p.Context`. Injecting records into `p.Context` by hand duplicates what P7 exists to do
- Assembly only at composition root: components inside must not create dependencies
- No stubs/sentinels: the brain parameters plus all six ports must be present; there is no "minimal runnable" path
- Organ composition over organ routing: hosts stack membranes and tool ports by wrapping organs in functions that return the same port type, not by adding a slot, an event or a config field — the loop keeps seeing exactly one of each, so composition costs the kernel nothing it did not already model
- One lifecycle timing, derived not declared: the framework brings organs up when it can type-assert `Bootable`, in the order the blueprint already lists its required ports (`PortOrder()`), so adding a port cannot leave its boot point unlisted; `hostOrgans` is the only hand-written sequence and a test pins it against `PortOrder()`. The alternative — a `Boot` method on every port — would force every host to write a no-op for a stage it does not need
- The stream is journalable through a shape the framework owns: `EncodeEvent`/`DecodeEvent` instead of `json.Marshal(Event)` — plain marshaling writes an `error` field as `{}`, numbers enums that a later release may reorder, and reports nothing. The wire version-guards each record, names its enums, and marks any value it could not carry in `Dropped`; `Event.CellID` makes a merged log attributable to the cell that spoke
- An audit record describes, it does not possess: `ReplaceAudit` holds type names, not port values — it is emitted after the swap it records and has to survive being written to disk

## Pitfalls

- Host ports (Effector) must be concurrency-safe if same Agent is stimulated concurrently (the brain is stateless — one Prompt is a round's whole truth — so concurrent Thinks are safe by construction) — the cell snapshots the ports under its wire lock but owns no run lock, so two `Stimulate`/`Resume` calls on one Agent genuinely run two loops over one port instance
- An organ combinator (`GuardStack`/`FallbackEffector`) never forwards `Boot`: the framework asserts the capability on the port value it is handed, so a member that must come up first is booted by the host before it is composed
- `Boot` runs at the moment an instance joins an assembly: once during `New`, once each time a `Replace` takes it. The framework never closes an organ, so a Bootable instance reused across `New` calls would open its resources twice and be released once — a Bootable organ belongs to one assembly and is built per agent
- Pause is gap-effective: it never interrupts an in-flight Think/Act — interrupt a running tool with ctx cancellation instead; the honored pause ends the iterator (EventPaused + Session), so a pause inside a tool list keeps the current tool in Session.remaining and Resume runs it first
- Session (from EventWaitInput/EventPaused) is an opaque single-use handle: read it through `Kind()` and `RemainingCalls()`, never mutate it; it belongs to the cell that suspended it and `Resume` rejects a foreign handle (`ErrForeignSession`); resuming twice re-executes the remaining tool calls (duplicate side effects — host responsibility); persist across restarts via `Session.Marshal()` / `UnmarshalSession` (versioned JSON — v4 carries the owning cell, the wait kind and a withheld draft; an unknown wait name is rejected; timeout-deny remains host-controlled)
- Suspension path fires OnCycleEnd/AfterStimulate exactly once with empty output — distinguish via StateWaiting/EventWaitInput and do not persist an unfinished round; the outcome parameter reports OutcomeSuspended (`OnCycleEnd(ctx, output, outcome CycleOutcome)`: Done/Suspended/MaxRounds/Error/Aborted, zero reserved for consumer-abandoned iterators → Aborted)
- Stopping the iterator mid-cycle abandons the round; tools at or after the stop point do not execute
- Host ports must respect ctx (long operations must monitor ctx.Done)
- Hooks.BeforeThink must replace p.Context as a whole slice — it shares the backing array with lc.Context; appending into it can corrupt the loop's accumulated context
- Streaming UX rides `WithSink` on the Stimulate context; the event stream never carries token deltas (EventText is whole-segment by contract)
- Framework sentinels a host must match by identity are re-exported at api level: `ErrMaxRounds`, `ErrForeignSession` (a Session resumed by the wrong cell), `ErrCellClosed` (an invocation asked of a closed agent — the kernel wraps it with the call site, so match with `errors.Is`, never `==`) — `internal/` is not importable from a host, so a value that never reaches `api/` cannot be `errors.Is`-matched by one
- Facade adds no business logic (delegation only); extend semantics in capability packages or host
